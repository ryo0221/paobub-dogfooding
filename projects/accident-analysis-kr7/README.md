# KR-7 肘関節の停止遅れ（ヒヤリハット）

故障の原因解析と対策（failure-analysis 1.1.0）の工程で進める Project の主のリポジトリです。工程の状態と成果物のファイルは `workflow.json` にあります。

会社名・人物・製品・事故・数値はすべて架空です（実在のものとは関係ありません）。この進め方は、認証や承認された安全評価の代わりではありません。

## 何をしたか

協働ロボット KR-7 の肘関節が、停止指令の後も 0.4 秒動き続け（基準は 0.2 秒）、作業者の手が治具に挟まれかけた、というヒヤリハットを調べました。三つの分析を、それぞれ別の意味と ID のまま持ち、明示した引用だけでつないでいます。

| 工程 | 成果物 | 中身 |
| --- | --- | --- |
| 要因分析 | `docs/cause-diagram.graph.json`（特性要因図） | 原因の候補 CC-01〜CC-05。仮説・確認済み・除外の状態と、確かめ方を持つ |
| FMEA | `docs/fmea.data.json` | 故障モード FM-01、故障原因 FC-01（保持力が摩耗で落ちる）と FC-02（停止信号が遅れて届く）。根拠に、FC-01 は CC-01・CC-05、FC-02 は CC-03 を引用 |
| FTA | `docs/fta.graph.json`（故障の木） | トップ事象と OR ゲート、基本事象 BE-01・BE-02。BE-01 に FC-01、BE-02 に FC-02 を対応づけ |

FMEA と FTA は、2 つの会社の担当者が共同編集で同時に開いて作りました。品質保証部の森 みなみ（みなとロボティクス、Project の持ち主）と、ブレーキを納める設計部の工藤 はると（ひばり制動、編集を許された参加の組織）です。

- 片方が「候補から選ぶ」で引用を選ぶと、相手の画面にすぐ出ます。
- 保存したのが相手でも、それぞれの引用は「選んだ人が、選んだときに見ていた版」を基準（証跡 selection の仮の基準）として残ります（PaoBub #596、AR-P5）。
- その基準の記録を `records/fmea-basis.json` と `records/fta-basis.json` に書き出しています。

## 置いたもの

- `docs/`・`trace/`・`workflow.json`・`definition.json`
  - Project の main の中身です。
  - FMEA と FTA は、共同編集で保存した作業中の版（`work/fmea-analysis`・`work/fta-analysis`）を入れています。受け入れる前なので、`workflow.json` の工程の状態は未着手のままです。
- `records/`：共同編集の保存のあとに PaoBub から読んだ、引用の基準（`citation-basis`）です。
- `assets/`：共同編集の画面の静止画と、2 本の動画のサムネイルです。
- `promo/`：YouTube の説明文と日本語の字幕です。
  - 2 人の共同編集の動画（2 分 2 秒）：https://youtu.be/1kdrYOVTd-0
  - 1 人で三つの分析をつなぐ動画（2 分 11 秒）の説明文と字幕：`solo-*`
- `tools/`：動画を撮った Playwright の spec と、動画を組み立てるスクリプトです。
  - `collab/` は 2 人の共同編集、`solo/` は 1 人で三つの分析をつなぐ版です。
  - spec は PaoBub の `tests/e2e/` に置いて流します。流し方は各 spec の先頭にあります。
  - 動画は pyopenjtalk の音声合成、Noto Sans JP、ffmpeg で作ります（`video/build.py`・`video/thumbnail.py`）。

## dogfooding で見つかったこと

- 共同編集の FMEA と分析の図には、引用の欄（「候補から選ぶ」）がありませんでした。PaoBub #596 で直しました。
- 保存の再試行で、選び直した新しい選択が古い保存版に結び付くおそれがありました。#596 で、時刻ではなく保存の操作と証跡を直接ひも付け、対応が確かめられないときは「版不明」のままにしています。
- FMEA の引用の欄の見出しに、`refs.causeCandidates` という内部の名前がそのまま出ます。
- 古い引用の比べる画面と受け入れの窓に、属性が生の JSON で出ます。
- FMEA の表示の設定が壊れていると、何も言わずに白い画面になります。
