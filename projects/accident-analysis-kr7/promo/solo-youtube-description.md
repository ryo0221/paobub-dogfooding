## 説明文

協働ロボットの肘関節が、停止指令の後も 0.4 秒動き続け、作業者の手が治具に挟まれかけた。そんなヒヤリハットを、PaoBub で、特性要因図・FMEA・FTA の三つの分析をつないで調べました。

三つの分析の項目は、別の意味と ID のまま持ち、明示した引用だけでつなぎます。

・要因分析（特性要因図）：原因の候補（CC）に、仮説・確認済み・除外の状態をつける
・FMEA：故障原因（FC）の根拠に、原因の候補を「候補から選ぶ」でつなぐ
・FTA：基本事象（BE）に、対応する故障原因を選ぶ
・引用先が変わると、古い引用として出る。前と後を比べて「合わせる」か、理由を書いて「古いまま残す」を選ぶ
・規則に無い引用（故障原因 → 基本事象の逆向きなど）は、候補に出ず、ファイルに直接書かれても受け入れの前に止まる

名前が似ているだけで勝手につなぐことはしません。つながりは人が選んだものだけです。
