# 工程計画

## 対象と出口

対象はミッドシップの 2 人乗りスポーツカー「翔」（機構と外装。電子・ソフトは入れない）。この版の出口は詳細設計（P4）で、外形（外板・窓・床とディフューザー）の 3D モデルと図面の候補を出す。車体の骨格・サスペンション・灯火は次の版で詳細設計する。

## 工程の取捨

11 の工程をすべて通る。この版は進め方〜詳細設計（P0〜P4）まで。詳細設計は外形だけで、骨格と足回りは配置の箱と部品表の行だけ持つ。

## ゲート

- 判定者：製品の責任者

### GT-04 基本設計のゲート

## 段階と受入

外形は、比と配置 → 空気の通り道 → 線 → 塊 → 面 → 床の順に小さな段階で作り、それぞれ絵で見て受け入れた。詳細設計は面と床をまとめて受け入れる。

## AIに頼む範囲

AI が提案すること：要求の案、方式と外形の案、配置と面の 3D モデルの作成、寸法・比・面積・質量の解析、製造性の指摘。人が決めること：外形の案の選択（3 案から C）、要求の優先度、ゲートの判定、直さない指摘の判断。形状は 3D の CAD、解析はその形状のカーネル。画像は 3D の表示とレンダリングから撮る。

## 置き場と版

成果物は docs/ と cad/。配置モデルは cad/layout-model.cad.json、詳細モデルは cad/detail-model.cad.json、評価の生データは cad/check-report.json。受け入れた版は工程ごとに固める。
