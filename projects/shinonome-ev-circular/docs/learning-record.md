# 学びの記録

## 学び

### LE-01 市場全体から契約可能量まで段階を分けて見積もる

`pin/market/1` の MS-01、MS-02、MS-03 は電池を重量で、MS-04、MS-05、MS-06 は e-Axle を台数で見積もった。乗用 BEV の国内販売実績を起点に、販売から取り外しまでの年数を仮定して全体量（TAM）を試算し、回収網と取引先が届く量（SAM）、獲得できる量（SOM）へと絞った。`pin/financial-plan/2` の FA-01 は e-Axle の TAM を参照しており、売上を裏付けるには、契約可能量と取扱能力まで確認する必要があった。

**次の企画で変えること**　対象ごとに単位・出所・実績・仮定を明記し、排出元や買い手への聞き取りで到達範囲と契約可能量を確かめてから売上を積み上げる。

### LE-02 収支の前提と為替の感度を初期のモデルに入れる

`pin/financial-plan/2` の FA-01 はバーツ建て売上、FA-02 と FA-03 は円建て費用と設備投資、FA-04 は円換算の為替を仮定した。楽観・悲観シナリオ（SC-02、SC-03）が動かしたのは売上の前提であり、為替による採算・資金への影響は別に調べる必要があった。`pin/risk/2` の RK-04 は為替変動の影響を挙げ、`pin/investment/1` の IC-03 は複数水準での感度分析と契約通貨・ヘッジの検討を求めた。

**次の企画で変えること**　売上・費用・設備投資・税率・割引率の根拠と更新担当を記し、通貨別の収支を置いたうえで、売上と為替を動かした場合の採算と資金繰りを比較する。

### LE-03 実証の支出条件と本投資の再審査条件を先に決める

`pin/investment/1` の IC-01、IC-02、IC-04、IC-06 は採算、取引の裏付け、法令・安全、段階ごとの資金管理を判断条件にした。`pin/management-decision/1` の MD-01 は本投資を見送り、範囲・見積もり・資金の出し手・安全と法令の条件を財務と法務が確認することを前提に、電池の小規模実証に必要な費用を承認した。本投資の再審査には、契約可能な回収量と買い手の購入条件の裏付け、更新後の基本シナリオで正の NPV を求め、条件を満たせない場合は保留とした。

**次の企画で変えること**　投資審査に出す前に、実証の支出条件と本投資の再審査条件を分け、必要な証拠・確認する人・保留の扱いを審査資料に書く。

### LE-04 実証で集める記録を再審査に結び付ける

`pin/execution/1` の ML-02 は回収・輸送から診断・選別、処理・資源回収先への引き渡しまでの運用を試す計画を置いた。`pin/management-decision/1` の MD-01 と `pin/investment/1` の IC-02 は、作業・安全・受け入れ結果・費用に加え、回収量・発生時期・引き取り条件から契約可能量を確かめ、買い手の購入数量・価格・支払意向を収支の更新に使う必要を示した。e-Axle の工程・品質・保証条件は ML-03 と IC-05 が扱う後段の試作の論点であり、MD-01 が承認した小規模実証の対象は使用済み電池だった。

**次の企画で変えること**　実証前に、対象ごとの記録項目・記録担当・照合先と、どの結果で収支の前提や次段階の判断を更新するかを決める。

### LE-05 工程を依存関係の順に置き、後から入る根拠の戻し先を決める

`pin/process/1` の工程定義は、機会探索、仮説、市場・顧客、事業モデル、実行計画、収支、リスク、投資判断、計画書、説明資料、経営判断の順に成果物をつないだ。同版の進め方の判断記録では、先に書く仮説が後工程の市場規模や前提を参照する場合、引用を後工程で補って確認することも定めた。`pin/hypothesis/1` の HY-05 が置いた e-Axle の仮説に対し、`pin/market/1` の MS-04、MS-05、MS-06 と CS-05 が、市場の試算と聞き取り先を具体化した。

**次の企画で変えること**　工程を組むときに、各工程で受け取る根拠と後工程へ渡す項目を記し、後から得られる根拠をどこで仮説に戻すかを決める。

### LE-06 機械検査、成果物の承認、会議の判断を分ける

`pin/process/1` では工程定義を機械検査に通したうえで、人がその定義で進めることを承認した。市場調査の承認と企画を続けるかの会議判断も別の条件だった。`pin/investment/1` は実証費用の審査に出す提案を記し、`pin/management-decision/1` の MD-01 は経営会議で承認した支出の範囲と再審査条件を記した。何を検査し、誰が何を決めたかを分けて記録すると、次に進める範囲をたどれる。

**次の企画で変えること**　各節目で、コマンドで検査する項目、人が成果物を承認する条件、会議が判断する事項と判断者をそれぞれ定義する。

### LE-07 マインドマップと収支モデルで後工程に渡す情報を明確にする

`pin/opportunity/1` のマインドマップは OP-01 の回収・選別の機会と CP-01 の回収先を確保したいという困りごとを枝で示した。`pin/business-model/1` は VF-01 の回収などの価値の流れと、RS-01 の回収手数料などの収益の柱を見渡せる形にした。`pin/financial-plan/2` の収支モデルは、FA-01 などの入力前提、SC-01 などのシナリオ、AR-01 などの計算結果を区別し、前提を更新したときに採算を比較できる形にした。

**次の企画で変えること**　候補と関係はマインドマップで整理し、収支は前提・単位・シナリオ・計算結果を分けたモデルにして、後工程で参照する項目に識別子を付ける。

### LE-08 文書の JSON とスライドに異なる役割を持たせる

`pin/business-plan/1` の文書 JSON は、PC-02 に市場の試算と聞き取りの論点、PC-05 に収支の前提と結果、PC-07 に支出審査と本投資の再審査条件を置いた。`pin/presentation/1` のスライドは、SL-06 から PC-05、SL-08 から PC-07 を参照し、会議で説明する収支と判断事項を章に戻って読める構成にした。

**次の企画で変えること**　根拠をたどれる章構成で計画書を先に作り、スライドでは会議で判断してほしいことを絞って、根拠となる章を参照する。

### LE-09 受け入れた版から引用し、後工程の受け入れ前に版を照合する

`pin/business-plan/1` の PC-05 と `pin/presentation/1` の SL-06 は、NPV・IRR・キャッシュフロー図を、収支モデルの受け入れ版 `pin/financial-plan/1` を指定して引用していた。今回の振り返りに渡された収支の固定版は `pin/financial-plan/2` であり、成果物それぞれの受け入れ状態に加え、下流の引用がどの版を指すかを照合する必要があると分かった。

**次の企画で変えること**　後工程を受け入れる前に引用先の項目と版を照合し、版を更新するときは文書とスライドの表示値や図も照合する。

### LE-10 工程ごとの負荷から運営費と設備投資を積み上げる

`pin/plant-twin/1` の TR-01・TR-02 は電池と e-Axle を同時に流した場合の人員・設備と処理能力を見積もり、TR-03・TR-04 はその構成から運営費と設備投資を積み上げた。`pin/financial-plan/3` の FA-02・FA-03 では、拠点の運営費に加えて、増設費を発生年の費用に、立ち上げ設備・改装と実証・試作の器材を初期投資に計上した。`pin/business-plan/2` の PC-08 が比較した前後の試算では、初期設備投資は 12 億円から 1.71 億円、2035 年の年間費用は 9.2 億円から 3.57 億円になった。費用が変わった理由を人員・設備・単価・計上時期までたどれるようになり、実測や現地見積もりで置き換える仮定も明確になった（TR-05、`pin/investment/2` の IC-12）。

**次の企画で変えること**　工程の負荷から人員・設備を見積もり、立ち上げ・増設・運営の費用を計上時期別に積み上げ、実測や現地見積もりで更新する前提を明示する。

### LE-11 採算の試算と売上の裏付けを別々に判定する

`pin/financial-plan/3` の AR-07 では基本の NPV が正になった。売上は市場推計と模型の処理能力に、仮定の単価・歩留まりを組み合わせた試算だった。`pin/investment/2` の IC-07・IC-08 は採算と取引の裏付けを別々に判定した。契約可能な回収量と買い手の購入条件に裏付けがなかったため、`pin/management-decision/2` の MD-02 は本投資の保留を続け、MD-01 で費用を承認した使用済み電池の小規模実証を進めるとした。

**次の企画で変えること**　実証で排出元別の契約可能量、買い手の購入数量・価格・支払意向、選別後の歩留まりを確かめ、収支に反映してから本投資を再審査する。

### LE-12 模型の再現性を機械検査に組み込む

`pin/plant-twin/1` の TR-01・TR-02 が示す市場量と能力試験について、模型を再実行し、処理完了数が保存済みの結果と一致するかを機械検査にした。再実行の出力全体と、年別の完了数・年換算能力の照合結果も残す形にした。確かめ役はコマンドを実行せずに計算の再現性を追え、工程時間や設備停止、手戻りの仮定が現場に合うかは TR-05 の実測で検証できる。

**次の企画で変えること**　模型を再実行して保存結果と照合する検査を設け、条件ごとの照合結果を、現場で確かめる前提とともにレビューに渡す。

### LE-13 外部 Editor の出所と引用表を保存後に照合する

収支の外部 Editor で出所を更新した際、引用表には以前の参照先が残った。`pin/financial-plan/3` の FA-01 は処理能力の出所に TR-02、FA-02 は運営費の出所に TR-03、FA-03 は立ち上げ設備の出所に TR-04 を記している。収支の入力画面に出る出所と、後工程が根拠をたどる引用表には、それぞれ更新内容が反映されたかを確認する必要があった。

**次の企画で変えること**　外部 Editor で出所を変えたら、受け入れ前に保存した内容と引用表を項目ごとに見比べ、追加・削除した参照先が両方に反映されているか確かめる。

### LE-14 初回の版と判断を残して再審査を重ねる

MD-01 の本投資の見送りを残し、拠点の模型（`pin/plant-twin/1`）を作って収支計画を開き直した。収支を `pin/financial-plan/3` に更新し、`pin/risk/3` と `pin/investment/2` の IC-07〜IC-14 で当初の条件を再点検した。`pin/business-plan/2` の PC-08 と `pin/presentation/2` の SL-09〜SL-13 に再審査の内容を加え、`pin/management-decision/2` に MD-01 と MD-02 を残した。初回と再審査の根拠をそれぞれたどれるため、どの前提が変わり、どの条件が引き続き満たされていないかを比べられた。

**次の企画で変えること**　初回の受け入れ版と判断を保存し、再審査では影響を受ける成果物を依存順に更新して、前後の版と前回の判断条件を新しい判断から参照する。
