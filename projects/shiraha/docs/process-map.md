# 進め方

架空のアニメの架空のメカを作る Project です。実在の作品・会社・商品とは関係がありません。

## 題材と出口

- 作るメカ：新しい独自の可変機 1 機（既存のメカの見直しではない）。大人の視聴者に向けた、白を基調にした細身の機体。白鳥のような美しさ。
- 変形：飛ぶ形（白鳥の形）と人の形を、1 機で差し替え無しに行き来する（合体はしない）。
- 前の Project（救都合体ミチビキオー（仮））は、子供向けに寄りすぎたため仕切り直した。そこで分かった「寸法の突き合わせ」と「CADで動かす検証」はこの Project でも必ず通す。
- 出口：設定画の決定稿・3Dモデル（骨格と外装を分け、変形が成り立つことを動かして確かめたもの）・大人向けフィギュアの見込み・色彩・見せ場の絵と動画。最後に、東京駅の前で決めのポーズを取る絵を作る。

## 承認の条件

- どの工程も、スタジオ暁 1 人・アトリエ鋼 1 人・ホシノ玩具 1 人の承認で受け入れる。
- 3 社のどこかが「否」なら差し戻す。差し戻しは線図・比率など形の元の工程へ戻して
- 格好の良し悪しは、案を並べて監督とメカデザイナーが選ぶ。AI の所見は参考にとどめ、選んだ理由を判断として残す。直す。

## AIの関与

- AI に任せる：企画の案出し、変形の構想の案、シルエットの案と評価の観点ごとの所見、線図の案（2 次元）、変形図、3Dモデル化、動かしての干渉の確認、描画（Codex の画像生成を含む）と動画。
- 人が決める：コンセプト・新しさ・どの案を採るか（格好の良し悪しは AI に決めさせない）・承認。
- 人が手で直す：AI の出した表・線図・モデルの寸法や言葉を、各 Editor で直して保存する。直した所と理由を成果物に残す。

- 権利：既存の作品のメカ・名前・標章・決めのポーズを写さない。白い主役機の定番（白い頭・V 字の角・青い目の組み合わせ）に寄せない。実在の航空機の意匠もそのまま写さない。
