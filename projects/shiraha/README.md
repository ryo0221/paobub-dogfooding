# 可変機 白羽（シラハ）

PaoBub の「アニメのメカデザインと玩具化」（mecha-design 1.2.0）の工程で作った、オリジナルの可変機の Project です。

> **オリジナルの機体です。** 白羽の名前・形・設定は、この Project で作ったものです。既存の作品・メーカーのデザインは使っていません。登場する 3 社（アニメ制作・デザイン事務所・玩具メーカー）と担当者は、手元の PaoBub で動かした架空のペルソナで、実在の会社・人とは関係がありません。

- 白鳥のような「飛ぶ形」から、人の形へ変わる 1 機の可変機です。大人向けのコレクション・フィギュアを想定し、白を基調にした細身の機体にしました。白鳥の頭は外せる兜で、外すと人の顔（素顔）が現れます。
- 工程は、進め方・企画（コンセプト・特徴・新しさ）・シルエット・線図（三面図）・変形の仕組み・3D モデル・設定画・玩具の確認・配色の 10 工程を受け入れ済みです。発表と公開の 2 工程は未着手です。
- 3D モデルは PaoBub の作業役（Codex）が CAD で組み、人は CAD の絵の上の注釈で直しを伝えました。152 部品、21 の姿勢（飛ぶ形・変形の途中・人の形・素顔・決めのポーズ）で、どの姿勢でも干渉は 0 件です。
- 3D の背景は東京駅・丸の内駅前広場のデジタルツイン（国土交通省 Project PLATEAU）です。

## 3D モデルの版について

- `docs/model-3d.json` の工程は `pin/model/2` で受け入れ済みです。
- その後、作業役が `work/model` で次の直しを続けました。ここに置いた `cad/` と `review/` は、その最新（作業の途中で止めた版、コミット 9c96744）です。
  - 翼：骨に沿って風切羽と雨覆を重ねた、鳥の翼にしました。決めのポーズでは扇に開きます。
  - 素顔：兜を外した人の顔を作り直しました。
  - 兜：耳の軸 → アーム → 兜の付け根の 2 段の関節で、設定画のとおりに開きます。最後に嘴が回って、首の後ろで下を向きます（`SP-04 兜を外す` 25・50・75・100%）。
- 最新の版は、まだ受け入れていません。PaoBub で開くと、3D モデルの工程に受け入れ後の変更として出ます。

## 道具の課題（PaoBub・Editor Platform に送る）

- 作業役の 1 回の作業が 2〜3 時間かかり、途中の様子と終わる時刻が見えない。
- 作業役の見比べが「3 / 3 回目」の後に「1 / 3 回目」へ戻って終わらず、手で止めた（2 回）。
- 確かめ役が画像を見られず、線図との重ね合わせを確かめられない。3D モデルの受け入れが「一部」で止まった。
- 工程の定義を直しても、既にある Project の成果物の置き場が足されない（`workflow.json` を手で直した）。受け入れ済みの工程は、定義の変更後も「満たす」のまま。
- 作業役の CAD が CAD のエディターでなく表で開く。レビューに画像を貼れない。注釈の作者が「あなた」になる。
- 作業役のモデルの切り替えが環境変数で、作業役の入れ直しが要る。
- CAD のロフトが断面の始点の位置で失敗し、書き出しでは片側の部品だけが例外になることがある。
- 姿勢の間の動き（補間）、カメラ、動画の書き出しは、道具の外のスクリプトで作った。
