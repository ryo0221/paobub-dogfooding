# 施工中の構造の確認

この版では、施工中の構造の確認を省きました（工程の状態は「省いた」）。

## 解析の場合

- なし。

## 解析の条件

- 省いた理由：段階ごとの解析（立っている鉄骨を梁の要素で解く）には、構造の計算の道具（CalculiX を入れた Reference Host）が要る。この版を作った環境には、それが無かった。
- 代わりの確認：揚重の検査で、昇りの支え（タワークレーンが立つ環）が、その日に建っていることを確かめた（SI-008）。クレーンの基礎の反力と、昇った後に環に載る重さ（タワークレーン 1 台 150 t）は確かめていない。
- 次の版で：タワークレーンが昇った日（TK-011・TK-013・…）と、ゲイン塔の引き上げの日（TK-041〜TK-045）を解析の場合にし、完成時と比べる。
