# D-05 採用見本は、いま採っているものがない（外部の見本を入れていない）

- 種類：結論
- 操作：決める
- 状態：有効
- 問い：採用見本は、いま採っているものがない（外部の見本を入れていない）
- 候補：採る｜見送る
- 選んだもの：採る
- 文：依頼に見本の指定がなく、AI は外部の作品や画像の出典・利用条件を確かめられないため、採用見本は「なし」にして、加えるときの条件（出典・利用条件・外へ送ってよいか・固定した版の4つ）だけ書いた。最初の候補は、設定画ができたあとの作者自身の設定画の固定した版。見本が1つもないので、達成条件「どの採用見本にも出典などが書いてある」は、該当する見本がない形で満たす。見本を入れたいなら、作者が候補を挙げて決める。
- 理由：AIのおすすめどおりで進める。
