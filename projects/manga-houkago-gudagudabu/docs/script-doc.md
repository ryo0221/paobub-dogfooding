# 脚本：放課後ぐだぐだ部

> 書き方の約束：「作者の指定」は依頼や承認済みの判断に書かれていること。「AI の案」は AI が補った案で、作者が採否を決める（承認するまで決まりではない）。台詞はすべて AI の案（判断 D-02）で、作者が採否・書き直しを決める。

## 書き方

- 作者の指定：第1〜3話・各8ページ。ボケはねむ、ツッコミはすず、たけしは存在に気づかれない笑い。台詞は短く、ギャグのテンポを重視する。毎話のラストは、部室でお茶をすする一コマ（最後のコマ）。
- AI の案：シーンの分け方・ページの割り当て・視点・葛藤・変化・小さなギャグの運び・台詞の中身と言い方・ト書き。
- シーンは `### SC-nnn`、台詞は `#### DL-nnn` の見出しで置く。番号は話に依らず作品の中で固定し、使い回さない。
- 描く出来事は、筋の台帳（pin/story/1）の出来事・筋・伏線の ID で引く。示す順は、構成図（docs/structure-map.json）の提示位置（OC-nnn）で決める。
- 台詞の項目：話す人物（人物表の ID）・言い方・声か心の声か・台詞。ト書きは台詞と分け、台詞の見出しの下に「ト書き（直前）」として書く。台詞のないところのト書きは、シーンの「ト書き」に書く。
- 台詞の表記は、画作りガイドの文字の決まり（終わりに「。」を付けない・「！」「？」は全角・「……」は2つ続ける）と、固有名詞と表記の辞書に従う。「特になし」はかぎかっこで書く。
- 呼び名（AI の案。人物表の口調に従う）：ねむ→すず「すずちゃん」、れいか→ねむ「朝比奈さん」、れいか→すず「小鳥遊さん」、すず→ねむ「部長」、すず・ねむ→れいか「会長」、すず→たけし「たけし先輩」。たけしは、名前を呼ばれないときは「先輩」。初めて出る難しい固有名詞（小鳥遊・権田原）には、写植で初出のルビを付ける（言い方の欄に印を付けた）。
- 本編のギャグの誇張は、見た目と台詞の中にとどめる。超自然は起きない（世界の覚え書き）。
