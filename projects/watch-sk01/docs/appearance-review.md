# 外装の確認

## 確認

画像は 3D の表示から撮った。注意：画像はラグを直す前（DM-01、ラグの間 11.2 mm）の形で撮ったもので、ラグの間は今の 3D モデルより狭く見える。

### AP-01 表から見た透け

- 見たもの：assets/appearance/watch-dial.jpg（表）
- 所見：見返しとインデックスで時刻が読め、地板の丸い穴から歯車が見える。中心の針のまわりの歯車が混み、時針が埋もれ気味
- 判定：条件付き合格：時針を太くするか白くする（次の版）
- もとにしたもの：DT-01・BD-001・BD-066・BD-079

### AP-02 細いベゼルと広い風防

- 見たもの：assets/appearance/watch-three-quarter.jpg（斜め）
- 所見：ベゼルが細く、風防が広く見える。リューズが小さく見える
- 判定：合格
- もとにしたもの：DT-02・BD-075・BD-076・BD-074

### AP-03 磨きと筋目の対比

- 見たもの：assets/appearance/watch-close.jpg（寄り）、assets/appearance/watch-back.jpg（裏）
- 所見：受けの筋目と地板のペルラージュが区別できる。金色の歯車が骨格の灰色に映える
- 判定：合格
- もとにしたもの：DT-03・BD-008・BD-017・BD-001

### AP-04 分解して見た部品の並び

- 見たもの：assets/appearance/watch-exploded.jpg
- 所見：部品の重なりの順が分かる。外装とムーブメントの比率が見える
- 判定：参考
- もとにしたもの：DT-01・BD-068・BD-001

## 隙間と面差

ベゼルと胴の段差 0.2 mm、裏ぶたと胴の段差 0 mm（同じ径）。リューズと胴のすき間 0.3 mm。面の連続は平面と円筒だけなので確認の対象にしない。
